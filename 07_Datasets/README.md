
# Datasets and Practice Data

This section contains datasets for developing and practising business analytics, data analysis and operations management skills.

## Dataset Categories

- Business and Financial Data
- Sales and Revenue Data
- Customer and Marketing Data
- Operations and Productivity Data
- Supply Chain and Logistics Data
- Inventory and Procurement Data

## Data Preparation

Datasets will be organised and prepared through:

1. Data collection and importing
2. Data inspection and understanding
3. Data cleaning and transformation
4. Handling missing and inconsistent values
5. Data validation and preparation for analysis

## Dataset Usage

Each dataset will support practical analytical exercises and portfolio projects involving:

- Microsoft Excel
- SQL
- Python
- Power BI
- Tableau

## Documentation

Where applicable, each dataset will include:

- Dataset name and source
- Description of variables
- Data dictionary
- Data quality observations
- Related project or analysis

Only datasets with appropriate usage permissions will be included.
